## 使用方法

影视仓/影视 → 设置 → 订阅管理 → 列表订阅，填入：

```
https://cdn.jsdelivr.net/gh/lhw828/tvbox-sources@main/subscriptions/iptv_own.json
```

或直接用 m3u（通用播放器）：

```
https://cdn.jsdelivr.net/gh/lhw828/tvbox-sources@main/subscriptions/iptv_own.m3u
```

本源与点播订阅相互独立，互不影响。
